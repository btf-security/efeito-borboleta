# Como contribuir

Obrigado pelo interesse. Este projeto só fica bom com a experiência de quem faz TPRM no
dia a dia.

## O que é bem-vindo

- **Prompt** que você usa e funciona. Mande a versão boa, uma versão ruim que você já viu
  dar errado e uma explicação curta da diferença.
- **Checklist** de algo que você faz com frequência (onboarding de fornecedor, revisão
  anual, saída de fornecedor).
- **Modelo** de documento (cláusula, política, relatório).
- **Correção de norma**: mudou um prazo, saiu uma resolução nova, um artigo foi revogado.
- **Melhoria numa skill**.

## Regras

1. **Fonte em tudo que for fato.** Norma com número e link oficial. Dado de mercado com
   relatório, edição e ano.
2. **Nada de dado de empresa real exposto.** Exemplos usam empresas fictícias. Não cite
   incidente de uma empresa sem fonte pública confiável.
3. **Nada de técnica ofensiva ativa.** Varredura de porta, força bruta, uso de credencial
   vazada e afins não entram, mesmo "para fins educativos".
4. **Português do Brasil, frases curtas.** Termo técnico em inglês pode, se for o que o
   mercado usa (TPRM, OSINT, SOC 2).
5. **Sem propaganda.** Material que só funciona com um produto específico não entra.

## Como enviar

1. Faça um fork e crie uma branch com um nome curto (`prompt-clausulas-contrato`).
2. Coloque o arquivo na pasta certa, seguindo o formato dos que já existem.
3. Abra um Pull Request dizendo o que é e onde você usa.

Prefere não mexer com Git? Abra uma issue com o conteúdo e a gente organiza.

## Código de conduta

Participando, você concorda com o [Código de Conduta](CODE_OF_CONDUCT.md).
