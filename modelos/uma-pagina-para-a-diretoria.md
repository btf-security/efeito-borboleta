## Dicas de uso

- **Nada de score sozinho.** "Nota 62" não diz nada para quem não conhece a escala. Diga
  o que a nota significa para o negócio.
- **Traduza o jargão.** "MFA" vira "segunda etapa de login"; "SOC 2" vira "auditoria
  independente de segurança".
- **Nomeie o fornecedor** quando o risco for dele. A diretoria precisa saber de quem se
  trata para decidir.
- Para gerar um primeiro rascunho com IA, use o
  [prompt de resumo para a diretoria](../prompts/resumo-para-diretoria.md).
